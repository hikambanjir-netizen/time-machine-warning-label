The funniest one-line warning label for a time machine, in 120 characters or fewer — written straight-faced, like a genuine safety notice, with the punchline landing on the last words.

> WARNING: This machine has no undo button. Your mistakes are now historically accurate.

A time machine has no undo: every mistake you make in the past becomes the history everyone has to live with. That is the hazard, the joke, and the whole label in 86 characters.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt`. Pure Python 3.13 standard library — no dependencies, no network, no randomness; two runs produce byte-identical output.
